# qx - Network Traffic Management & Proxy Configuration Tools

A collection of open-source network utilities and proxy routing configurations for developers and advanced users who need to manage network traffic, monitor bandwidth, and configure proxy rules.

## Features

- **Clash Proxy Rules**: YAML-based routing configurations for network traffic splitting
- **Bandwidth Speed Test**: Standalone JavaScript utility for network performance monitoring
- **Cookie & Session Management**: Configuration templates for network automation
- **MIT Licensed**: Free to use, modify, and redistribute

## Use Cases

- Developers managing network traffic in testing environments
- Users who need custom proxy routing for security research or development
- Network administrators requiring bandwidth monitoring tools
- Anyone needing reusable, documented network configuration templates

## Installation

1. Clone this repository
2. Import the desired configuration files into your network management tool
3. Customize rules according to your specific needs
